# php native mvc - Data buku
Membuat Aplikasi CRUD sederhana untuk mempelajcari
pola Model-View-Controller pada PHP Native.
Struktur MVC
`app/models/` : akses dan operasi data.
`app/controllers/` : alur request dan pemanggilan Model/View.
`app/views/` : tampilan HTML.
`config/` : konfigurasi koneksi database.
`database/` : skema dan data awal SQL.
`public/` : entry point aplikasi.

Fitur
 Menampilkan data buku
 Menambah data buku
 Mengubah data buku
 Menghapus data buku
 Validasi input dan pesan berhasil/gagal
